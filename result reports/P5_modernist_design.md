## C. Critical Path

### C-1. 의도적 예외 (디자인 규칙과 다르게 한 곳)
- **맵 이미지·브롤러 초상화는 컬러 유지.** 시스템은 사진을 흑백으로 찍으라고 하지만, 맵의 물·수풀·팀 색은 정보다. 흑백이면 전략 판단이 틀어진다.
- 사용자가 고른 **역할 색**과 **그림 팔레트**는 데이터·기능이라 토큰으로 바꾸지 않았다.
- 캔버스 위의 둥근 브롤러 토큰·화살표는 그림 내용이라 "모서리 0" 규칙 대상이 아니다.

### C-2. `[hidden]` 전역 규칙
시스템의 `.btn{display:inline-flex}` 가 HTML `hidden` 속성을 이겨서, 숨겨야 할 'Undo import' 버튼이 보였다(발견 후 수정). `[hidden]{display:none!important}` 를 앱 층에 둔다. **새 요소를 숨길 때는 `hidden` 속성을 쓸 것.**

### C-3. 외부 글꼴
Archivo 는 Google Fonts 에서 받는다(시스템 스타일시트의 `@import`). 오프라인이면 system-ui 로 대체되어 동작에는 영향 없다.

### C-4. 모바일
작은 화면(≤650px)에서는 헤더가 두 줄이 되어 고정(sticky)이면 내용을 가린다 → 모바일에서는 헤더 고정 해제.

### C-5. 리뷰에서 고친 것
- **선택된 도구에 마우스를 올리면 라벨이 사라졌다 (높음)**: hover 규칙의 선택자 우선순위가 active 보다 높아 빨간 배경이 지워지고 흰 글씨만 남음(대비 1.1:1).
- **브롤러 카드를 키보드로 못 골랐다 (높음, 기존 결함)**: 노트·역할·티어 변경이 마우스 전용이었다 → 카드를 버튼으로(Enter/Space), 패널에 **"Move to S–D"** 버튼 추가(터치에서도 드래그 없이 티어 변경).
- 창 폭 651~772px 에서 Import 후 헤더가 두 줄이 되며 사이드바 윗부분을 덮어 클릭이 막힘 → 헤더 실제 높이를 `--top-h` 로 추적.
- 대화상자: 포커스가 안으로 안 들어가고 Esc 무시, 닫으면 포커스 유실 → 시스템 `.dialog` 마크업 + 포커스 이동·가두기·Esc·복귀.
- 다시 그려지는 버튼(맵·모드·역할·버전·티어)이 포커스를 잃음 → 같은 키의 새 버튼으로 복귀.
- 흐린 보조 글자·placeholder 가 WCAG AA 미달 → neutral-700. 작은 강조 글자 → accent-700.
- 사용자가 고른 역할 색 위 흰 글씨가 밝은 색에서 안 보임 → 색 밝기로 글자색 선택.
- 그 외: 눌림 상태, 포커스 링, aria-pressed/aria-current, 아이콘 aria-hidden, 건너뛰기 링크, 중복 ⚠ 아이콘·옛 안내 문구.

## D. 새로 도입한 것

| 무엇 | 설명 |
|---|---|
| `css/modernist.css` | 디자인 시스템 원본. **직접 수정 금지** — 디자인을 바꾸려면 Claude Design 쪽 시스템을 고치고 다시 복사 |
