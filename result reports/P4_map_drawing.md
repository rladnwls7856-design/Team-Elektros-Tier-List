# P4 — 맵 이미지 그림판

> 2026-10-07 · 그림 엔진 테스트 80개(전체 294개) 통과 · 브라우저에서 펜·직선·화살표·텍스트·브롤러 아이콘·이동·지우개·실행취소/다시실행·PNG 저장 검증
> 엔진(`js/drawing.js`)은 워크플로로 테스트 우선 구현 → 2관점 리뷰(11건 발견) → 전부 재현·수정.
> 화면 연결 후 리뷰(P3 리포트와 같은 회차)에서 확인된 입력·내보내기 결함도 수정.

## A. 무엇을 · 왜

| 기능 | 동작 |
|---|---|
| 보기(View) | 그리지 않고 스크롤·보기만. **터치 화면의 기본 도구** — 맵 위를 스와이프하면 그림이 아니라 페이지가 스크롤 |
| 펜 | 색 8개 + 직접 선택, 굵기 S/M/L. 놓는 순간 점을 단순화(RDP)해서 저장 (실측 41점 → 28점) |
| 직선 / 화살표 | 드래그. 클릭만 한 경우(길이 0)는 저장하지 않음 |
| 텍스트 | 클릭 → 입력창(최대 200자). 넘으면 잘라내지 않고 거부 |
| 브롤러 아이콘 | 상자에서 브롤러 선택 → 클릭. 초상화를 원형으로 표시, 이미지가 없으면 이름 첫 글자 원 |
| 이동 | 맨 위 도형을 잡아 이동. 가장자리에 부딪혀도 모양이 찌그러지지 않음 |
| 지우개 | **닿은 도형을 통째로** 지움(벡터라 픽셀 지우기 없음) |
| 실행취소/다시실행 | 이미지(버전)별, 이번 세션 한정, 100단계. Ctrl+Z / Ctrl+Y (입력칸 밖에서만) |
| 전체 지우기 | 확인 후. 이것도 실행취소 가능 |
| PNG 저장 | 원본 해상도 이미지 + 그림 + 초상화 → `맵 - 모드.png` |

**좌표계**: 이미지 기준 0~10000 정수(x 는 너비, y 는 높이 기준), 굵기·글자 크기는 너비 기준. 그래서 데스크톱(414px)·모바일(321px, 2배 픽셀) 어디서든 같은 자리에 그려진다. 판정(지우개·이동)은 이미지 종횡비(`aspect`)를 넘겨야 정확하다.

## C. Critical Path — 데이터 정합성 · 성능

### C-1. 크기 상한 (그림 데이터는 Export 파일과 localStorage 에 들어감)
- 이미지 하나: 도형 ≤ 2,000, **점 ≤ 20,000** (≈ 240K 자). 펜 한 획 ≤ 2,000점.
- 상한을 넘는 획은 그리지 않고 "This map's drawing is full" 을 띄운다. 저장된 데이터·Import 데이터에서 상한 초과분은 `normalizeShapes` 가 버리고 경고에 센다.
- ⚠️ 이 상한은 **임의값**. 실사용(획 15·화살표 6·아이콘 5·텍스트 3)은 맵당 ~5K 자.

### C-2. 신뢰 경계
- 색은 `#rrggbb` 만 캔버스에 도달(엔진이 렌더 직전 재검증). 텍스트·브롤러 이름은 `fillText` 로만 그려 HTML 로 해석되지 않는다.
- 초상화 URL 은 **도형 데이터가 아니라 roster(API) 에서** 고른다. Import 파일이 임의 URL 을 넣을 수 없다.

### C-3. PNG 저장과 CORS
- 초상화 CDN 이 `Access-Control-Allow-Origin: *` 를 보내므로 `crossOrigin="anonymous"` 로 받아 캔버스를 오염시키지 않는다(실측 89KB PNG 생성).
- 실패하면 초상화 없이 다시 시도하고, 그래도 안 되면(로컬 `file://` 로 연 경우) 웹 주소로 열라고 안내한다.

### C-4. 리뷰에서 고친 것 (입력)
- **Ctrl+Z 가 노트를 지웠다 (중간)**: 그리기 시작 시 `preventDefault` 때문에 포커스가 마지막 입력칸에 남아, Ctrl+Z 가 그림이 아니라 **맵 노트 텍스트를 지우고 자동 저장**했다(화면 밖이라 안 보임). → 그리기 시작 시 포커스 해제, 단축키 예외는 텍스트 입력칸만.
- **창 너비만 바뀌면 캔버스가 어긋났다 (중간)**: 이미지는 가운데로 이동했는데 캔버스는 그대로 → 획이 이미지 너비의 ~24% 옆에 저장. → 무대(stage)·창 크기 변화도 감지.
- 두 번째 손가락이 진행 중인 획을 가로챔 → 첫 포인터만. 이동 도구로 클릭만 해도 다시실행 기록이 사라짐 → 실제로 움직였을 때만 기록.
- PNG 대기 중 맵을 바꾸면 다른 맵 이미지에 그림이 합쳐짐 → 바뀌었으면 중단하고 안내.

### C-5. 실행취소 기록은 세션 한정
- 새로고침하면 기록이 사라진다(그림 자체는 저장됨). Import·링크·Undo import 로 보드가 바뀌면 기록을 비운다 — 다른 보드의 상태로 되돌리는 사고 방지.

## D. 새로 도입한 것

| 무엇 | 설명 |
|---|---|
| `js/drawing.js` (`window.BrawlDrawing`) | 순수 벡터 엔진: `create*`, `normalizeShapes`, `hitTest/eraseAt/topShapeAt/moveShape`, `createHistory`, `render`, `LIMITS` |
| Pointer Events + `setPointerCapture` + `getCoalescedEvents` | 마우스·터치·펜 공통 처리, 빠른 획도 부드럽게. 캔버스 `touch-action:none` |
| `ResizeObserver` | 이미지 크기가 바뀌면 캔버스 재배치(고해상도 화면은 devicePixelRatio 반영) |
